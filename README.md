
# 🌤️ Telegram Weather Bot

Telegram-бот для получения прогноза погоды с поддержкой геолокации, графиков и ежедневных уведомлений.

![Telegram](https://img.shields.io/badge/Telegram-Bot-blue.svg)
![OpenWeather](https://img.shields.io/badge/OpenWeather-API-orange.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

## 📋 Описание

Простой и удобный Telegram-бот для мониторинга погоды. Получайте актуальную информацию о погоде в любом городе мира или по вашим координатам, просматривайте прогноз на 5 дней и получайте персонализированные советы по выбору одежды.

## ✨ Возможности

- 🌍 **Погода по городу** - введите название города на русском или английском
- 📍 **Погода по геолокации** - отправьте свои координаты для точного прогноза
- 📊 **График температуры** - визуализация прогноза на 5 дней
- 🕒 **Почасовой прогноз** - детальная информация на ближайшие 12 часов
- 👕 **Советы по одежде** - рекомендации в зависимости от погоды
- 🔔 **Ежедневные уведомления** - получайте прогноз в выбранное время каждый день

### Подробные данные о погоде

| Параметр | Описание |
| :--- | :--- |
| 🌡️ Температура | Текущая и ощущаемая температура |
| 💧 Влажность | Процент влажности воздуха |
| 🔽 Давление | Атмосферное давление в гПа |
| 💨 Ветер | Скорость ветра в м/с |
| 🌦️ Условия | Описание погодных условий |

## 🛠️ Технологии

- **Python 3.8+**
- **pyTelegramBotAPI** - работа с Telegram Bot API
- **OpenWeatherMap API** - данные о погоде
- **APScheduler** - планирование ежедневных уведомлений
- **Matplotlib** - построение графиков
- **Requests** - HTTP запросы к API

## 📦 Установка

### 1. Клонируйте репозиторий

```
git clone https://github.com/ваш-username/telegram-weather-bot.git
cd telegram-weather-bot
```

### 2. Установите зависимости

```
pip install -r requirements.txt
```

### 3. Получите API ключи

#### Telegram Bot Token

1. Найдите [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен

#### OpenWeather API Key

1. Зарегистрируйтесь на [OpenWeatherMap](https://openweathermap.org/)
2. Перейдите в раздел [API Keys](https://home.openweathermap.org/api_keys)
3. Скопируйте ваш API ключ

### 4. Настройте ключи

Откройте файл `bot.py` и замените значения:

```
API_KEY = 'ваш_openweather_api_key'
BOT_TOKEN = 'ваш_telegram_bot_token'
```

> ⚠️ **Важно**: Не публикуйте ключи в открытом доступе! Рекомендуется использовать переменные окружения.

## 🚀 Запуск

```
python bot.py
```

После запуска бот будет доступен в Telegram. Найдите его по имени и нажмите `/start`.

### Основные функции

#### 1. Получить прогноз по городу

- Нажмите "🌆 Отправить город"
- Введите название города
- Получите актуальную погоду

#### 2. Получить прогноз по локации

- Нажмите "📍 Отправить геолокацию"
- Отправьте свою геолокацию
- Получите прогноз для вашего местоположения

#### 3. Настроить уведомления

- Сначала выберите город или отправьте геолокацию
- Нажмите "🔔 Установить время уведомлений"
- Введите время в формате `ЧЧ:ММ` (например, `09:00`)
- Каждый день в это время вы будете получать прогноз погоды

## 🔒 Безопасность

**Не храните API ключи в коде!**

### Рекомендуемый способ

Используйте переменные окружения:

```
import os
from dotenv import load_dotenv

load_dotenv()
API_KEY = os.getenv('OPENWEATHER_API_KEY')
BOT_TOKEN = os.getenv('TELEGRAM_BOT_TOKEN')
```

Создайте файл `.env`:

```
OPENWEATHER_API_KEY=ваш_ключ_openweather
TELEGRAM_BOT_TOKEN=ваш_токен_telegram
```

Добавьте в `requirements.txt`:

```
python-dotenv==1.0.0
```

И обязательно добавьте `.env` в `.gitignore`:

```
.env
```
